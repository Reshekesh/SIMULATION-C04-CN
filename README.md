# Secure Site-to-Site VPN Using Cisco Packet Tracer

## Project Description
This project demonstrates a secure site-to-site VPN connecting three branch offices using Cisco Packet Tracer. OSPF is used for dynamic routing, allowing communication between all branches.

## Network Devices
- 4 Cisco 2911 Routers
- 3 Laptops
- Copper Ethernet Connections

## Features
- OSPF Dynamic Routing
- Site-to-Site VPN
- End-to-End Connectivity
- Secure Inter-Branch Communication

## Verification
The network was tested using:
- `ping`
- `show ip route`
- `show ip ospf neighbor`
- `show ip interface brief`
